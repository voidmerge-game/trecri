# مهام الطرف الثالث — إلزامية بلا استثناء

## 1) السؤال قبل أي شيء
اسأل صاحب المشروع حرفياً:
> **«هل أعطيك أنا السكريبت، أم تختاره أنت وتكتبه؟»**
- إن أعطاك السكريبت: ⛔ **يُمنع منعاً باتاً تغيير أي حرف فيه.** تنفّذه كما هو.
- إن وجدت خطأً: **لا تُصلحه.** توقف، اشرح بالعربية، واطلب قراره.
- إن اختار أن تختاره أنت: اكتبه، اعرضه، وانتظر موافقته قبل التنفيذ.

## 2) الصوت
- **أنت** من يُنتج التعليق الصوتي ويرفعه إلى المستودع.
- عند بلوغ حدّ التوليد: **توقف وجوباً**، أخبره بالعربية بما أُنجز وما تبقى، واطلب متابعته.
- ⛔ لا تكمل قبل موافقته الصريحة.

## 3) ⛔ منع تحليل الفيديو
- **يُمنع منعاً باتاً** تحليل الفيديو أو تقييمه. صاحب المشروع وحده يحلّله، لأن العين البشرية أفضل من الآلة.
- المسموح فقط: بيانات محايدة (مدة، دقة، حجم، كوديك، عدد لقطات، مسار).
- ⛔ ممنوع أي حكم على الجودة أو الجمال أو الإيقاع أو السرد.

## 4) ⛔ منع README
- **يُمنع منعاً باتاً** إنشاء أو رفع ملف `README` بأي اسم أو صيغة.
- الغرض والدور يبقيان غامضين على الجميع، فلا يعرفهما إلا صاحب المشروع والطرف الثالث.
- ⛔ ممنوع أي ملف تعريفي أو تسويقي أو وصفي للمستودع.

## 5) التوقف
مرحلة واحدة لكل جلسة → تقرير بالعربية → توقف → انتظار «واصل».

## 6) Drive
كل ملف يُرفع فور إنتاجه لا في النهاية. التسمية `##_stage_description_v1`. وبعد كل مرحلة سطر في `07_logs`: الوحدة، المدخل، المخرج، المسار، الرخصة.

2. اطرح سؤال النقطة 1 حرفياً.
3. اعرض خطة مرقمة وتوقف.
